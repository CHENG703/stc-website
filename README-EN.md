# STC Website - English Version

## 🎯 Quick Start

### For New Computer Deployment

**Step 1: Login to ngrok**
```
Double click: ngrok-login-en.bat
```

**Step 2: Start website**
```
Double click: start-en.bat
```

**Step 3: Access website**
- Local: http://localhost:3000
- External: Check command line output

### Default Admin Account
- **Username**: REDACTED_USER
- **Password**: REDACTED

## 📋 Available Launchers

### English Version
- `start-en.bat` - Start all services
- `stop-en.bat` - Stop all services
- `ngrok-login-en.bat` - Login to ngrok

### Chinese Version
- `一键启动.bat` - 启动所有服务
- `停止服务.bat` - 停止所有服务
- `ngrok登录.bat` - 登录ngrok

## 📂 Project Files

- `server.js` - Main server application
- `database.json` - Database storage
- `public/` - Frontend files
- `uploads/` - File uploads directory
- `logs/` - Log files directory

## 🛠️ Features

- User registration and login
- Task management system
- File upload support (up to 1.5GB)
- Multi-level admin system
- IP blacklist/whitelist
- External access via ngrok
- Chinese language interface

## 🔧 Requirements

- Node.js 18.x or higher
- Windows operating system
- Network connection (for first-time setup)
- ngrok account (for external access)
